# ReaQLine

[English](README.md) | **日本語**

REAPER の中だけで完結する、ライブ進行コントローラです。

リージョンを**曲**、マーカーを**セクション**として、タイムラインからそのまま読み取ります。本番中に見るのは大きな表示と **GO / NEXT / STOP** の 3 ボタンだけ。ブラウザも外部プロセスも、別管理のセットリストファイルも必要ありません。

## ReaQLine を使う理由

REAPER で同期音源を流すライブは、アレンジビューを睨みながら目当てのリージョンを探す作業になりがちです。ReaQLine は、いま使っているプロジェクトをそのまま演奏用コントローラに変えます。

- **打ち込み直しゼロ。** 曲順はタイムライン上のリージョンの並び、セクションはマーカーから決まります。REAPER 側で並べ替えたら **Rescan** を押すだけです。
- **セクション単位のループ**を REAPER のオーディオエンジンに任せるので、サンプル精度でズレません。
- **曲間の自動連結 (FOLLOW)。** リージョンが隣接していれば継ぎ目なしで次の曲へ入ります。
- **ショートカットがそのまま使えます。** 操作していない間はキーボードフォーカスを REAPER 本体へ返すため、REAPER のアクションもフットスイッチも普段どおり動きます。
- **離れた場所からでも読める表示。** ウィンドウ幅に合わせてフォントとボタンが拡大します。ドッキングもフロートも可能です。

## 機能一覧

| | |
|---|---|
| **Live タブ** | 再生中の曲、セクション、残り時間、セクション/曲のプログレスバー、次のセクションと次の曲。大きな GO / NEXT / STOP ボタン。 |
| **Edit タブ** | 曲一覧 (リージョン順) とセクション表 (マーカー)。曲ごとの **FOLLOW**、セクションごとの **LOOP** チェックボックス。 |
| **曲末で自動停止** | リージョン終端で停止し、選択が次の曲へ移ります。GO を押すだけで続行できます。 |
| **ループ範囲の追従** | ループ範囲 (タイムセレクション) が常に再生中のセクションを指します。REAPER 標準のリピート切替でそのセクションが回ります。 |
| **LOOP 指定** | LOOP を付けたセクションは、入った時点で自動的にリピート ON になります。 |
| **FOLLOW 指定** | FOLLOW を付けた曲は、前の曲が終わると自動で始まります。隣接していれば継ぎ目なし。 |
| **外部再生の取り込み** | スペースキーやフットスイッチ、MIDI で REAPER 側から再生を始めても、再生位置から曲を特定して管理下に取り込みます。 |
| **キーボード透過** | ReaQLine のウィンドウを開いたまま、REAPER の全ショートカットが使えます。 |
| **プロジェクト単位の設定** | LOOP / FOLLOW の設定はプロジェクトに保存され、名前で識別するためリージョンやマーカーを動かしても維持されます。 |

## 動作要件

ReaPack (ReaTeam Extensions) から以下をインストールしてください。

- **ReaImGui** v0.9 以上
- **js_ReaScriptAPI** — キーボードショートカットの透過に必須

いずれかが未導入の場合、起動時にメッセージを表示して終了します。

## インストール

1. このリポジトリをダウンロード、またはクローンします。
2. `ReaQLine.lua` と `reaqline/` フォルダを、REAPER のリソースパス内に**同じ階層で**配置します。例:

   ```
   <REAPER リソースパス>/Scripts/QuanTRIOS/
   ├── ReaQLine.lua
   └── reaqline/
   ```

   リソースパスは **Options > Show REAPER resource path** で開けます。
3. REAPER の **Actions > Show action list** から **New action… > Load ReaScript…** を選び、`ReaQLine.lua` を読み込みます。`reaqline/` フォルダの登録は不要です。
4. *(任意)* `toolbar_icons/` 内の PNG を `<リソースパス>/Data/toolbar_icons/` へコピーします。REAPER を再起動後、ツールバーボタンを右クリックして **Change icon** から選択できます。HiDPI 環境では `_x2` を使ってください。

### 必ず変更する REAPER の設定

**Preferences > Audio > Playback** を開き、次の項目を **OFF** にしてください。

> Stop playback at end of loop if repeat is disabled

ON のままだと、ループを抜けた時点で次のセクションへ進まずに停止してしまいます。

## プロジェクトの作り方

ReaQLine は独自のセットリストを持ちません。タイムラインをそのまま読みます。

<!-- IMAGE: リージョン (曲) がいくつか並び、その中にマーカー (セクション) があるアレンジビュー -->
![リージョン = 曲、マーカー = セクション](docs/images/project-structure.png)

| タイムライン上の要素 | ReaQLine での意味 |
|---|---|
| **リージョン** | 曲。曲順 = タイムライン上の並び順。 |
| **リージョン内のマーカー** | セクション (Intro / A / B / Chorus など)。終端は次のマーカー位置、なければリージョン終端。 |
| **どのリージョンにも含まれないマーカー** | 無視されます。 |

守っておきたいルール:

- リージョンは時間軸上で**重複させない**でください。
- リージョン名は**一意**に、セクション名は**同一曲内で一意**にしてください。設定はこれらの名前で識別します。
- FOLLOW を使わない曲の後ろには、**1 秒程度の無音**を確保してください。曲末の停止判定に最大 1 フレーム (約 30 ms) の遅れがあります。
- 曲順を変えるときは REAPER 側でリージョンを移動し、Edit タブの **Rescan** を押してください。

## 使い方

UI の表示は英語です。以下では画面上のラベルをそのまま記載します。

### Live タブ

<!-- IMAGE: Live タブ。可能なら注釈付き (曲名 / セクション / 残り時間 / バー / ボタン) -->
<img src="docs/images/live-tab-annotated.png" alt="Live タブ" width="470">

| ボタン | 動作 |
|---|---|
| **GO** | 選択中の曲を先頭から再生。リージョン終端で自動停止します。 |
| **NEXT** | リピートを解除。シークは発生せず、再生はそのままセクション終端を越えて次のセクションへ進みます。REAPER 標準の *Transport: Toggle repeat* と等価です。 |
| **STOP** | 即時停止。再生中は GO の位置が STOP に変わります。 |

このほか、トランスポート状態 (PLAY / PAUSE / REC / STOP)、現在のセクションと残り時間、曲の残り時間、次のセクションと次の曲を表示します。残り 10 秒を切ると残り時間が赤くなります。

### Edit タブ

<!-- IMAGE: Edit タブ。FOLLOW / LOOP 列のある曲一覧とセクション表 -->
<img src="docs/images/edit-tab.png" alt="Edit タブ" width="450">

- **曲一覧** (左 / 上): タイムライン順の全リージョン。長さ、**FOLLOW** チェックボックス、LOOP セクション数を表示します。ダブルクリックでその曲を再生します。
- **セクション表** (右 / 下): 選択中の曲のマーカー。開始位置と長さ、セクションごとの **LOOP** チェックボックスを表示します。`>` が再生中のセクション、`@` がループ中のセクションです。ダブルクリックか **Go to this section** でシークします。
- **Rescan**: タイムラインを編集したあと、リージョンとマーカーを読み直します。

レイアウトはウィンドウ幅に応じて横並び / 縦積みが切り替わります。

### セクションをループする

ReaQLine は、再生中のセクションに合わせて REAPER のループ範囲 (タイムセレクション) を更新し続けます。リピートの ON / OFF 自体には**関与しません**。

いま鳴っているセクションを回したいときは、REAPER 標準の **Transport: Toggle repeat** を叩いてください。もう一度叩けばループを抜けて先へ進みます。フットスイッチや MIDI コントローラはこの標準アクションに割り当てれば十分で、ReaQLine 側への MIDI アサインは不要です。

ループ動作は REAPER のオーディオエンジンが処理するため、サンプル精度で動作します。

<!-- VIDEO/GIF (任意): Toggle repeat でセクションを回し、抜けるまでの様子 -->

**LOOP** を付けたセクションは、入った時点で自動的にリピートが ON になります。付けていないセクションではリピートに触れないので、手動操作と衝突しません。

### FOLLOW (次の曲へ自動で続ける)

Edit タブで曲に **FOLLOW** を付けると、前の曲が終わったときに自動で始まります。

- リージョンが**隣接**している場合: シーク無しで連続します。継ぎ目が出ません。
- リージョンの間に**間隔がある**場合: 次の曲の頭へシークして継続します。

1 曲目に FOLLOW を付けても効果がないため、`!` を表示します。

### 選択の追従

再生中は再生位置、停止中は編集カーソルとタイムセレクションに追従します。無効化はできません。

セクション表の選択行は「**次の**セクション」、`>` は「**現在の**セクション」を指します。現在と次を同時に読めます。

## 設定の保存先

| 内容 | 保存先 |
|---|---|
| LOOP 設定、FOLLOW 設定 | プロジェクト (`SetProjExtState`) |
| ドッキング状態 | グローバル (`SetExtState`) |

設定は曲名とセクション名で識別するため、リージョンやマーカーを時間軸上で移動しても維持されます。名前を変更した場合は設定し直しになります。

## トラブルシュート

- フッターの **DBG** を有効にすると内部状態が表示されます。`KB` 行はキーボード設定の適用結果、`DBG` 行は追従の基準、再生位置、リージョン終端、選択状態です。
- **日本語のリージョン名やマーカー名が文字化けする**: ReaImGui を更新するか、名前をローマ字にしてください。
- **ループを抜けると再生が止まる**: [必ず変更する REAPER の設定](#必ず変更する-reaper-の設定) を確認してください。
- **FOLLOW を付けたのに曲末で止まる**: 次のリージョンが隣接しているか、他のリージョンと重複していないかを確認してください。

## ファイル構成

<details>
<summary>ソースファイル</summary>

```
ReaQLine.lua           エントリポイント。状態を持ち、各モジュールを繋ぐ
reaqline/
  config.lua           定数と配色
  imgui.lua            ReaImGui 初期化、フォント、キーボード制御
  model.lua            プロジェクト走査、設定の保存と復元
  transport.lua        再生制御、ループ範囲、進行管理
  widgets.lua          描画の共通部品
  ui_live.lua          Live タブ
  ui_edit.lua          Edit タブ
  ui.lua               ウィンドウ枠、ドッキング、フォーカス返却
```

しきい値、配色、フォントサイズの調整は `config.lua` のみで完結します。

</details>
