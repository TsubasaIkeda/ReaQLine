# ReaQLine

REAPER 内で完結するライブ進行コントローラ。

リージョンを曲、マーカーをセクションとして扱い、本番の進行を制御します。
ブラウザ常駐や外部プロセスを必要としません。

## 依存

ReaPack (ReaTeam Extensions) から以下をインストールしてください。

- **ReaImGui** v0.9 以上
- **js_ReaScriptAPI** — キーボードショートカットの透過に必須

いずれも未導入の場合、起動時にメッセージを表示して終了します。

## インストール

1. `ReaQLine.lua` と `reaqline/` フォルダを、同じ階層に配置します。
   例: `<リソースパス>/Scripts/QuanTRIOS/`
   リソースパスは Options > Show REAPER resource path で開けます。
2. Actions > Show action list > New action… > Load ReaScript… で
   `ReaQLine.lua` を読み込みます。
   `reaqline/` フォルダは登録不要です。
3. `toolbar_icons/` 内の PNG を、リソースパスの `Data/toolbar_icons/` へ
   コピーします。REAPER を再起動後、ツールバーボタンを右クリックして
   Change icon から選択できます。HiDPI 環境では `_x2` を使ってください。

## REAPER 側の設定

- Preferences > Audio > Playback
  **「Stop playback at end of loop if repeat is disabled」を OFF**
  ON だとループを抜けた時点で停止します。

## プロジェクトの作り方

- リージョン = 曲。曲順はタイムライン上の並び順で確定します。
- マーカー = 曲内のセクション。セクションの終端は次のマーカー位置、
  なければリージョン終端です。
- どのリージョンにも含まれないマーカーは無視されます。
- リージョンは時間軸上で重複させないでください。
- 同名のリージョン、および同一曲内での同名セクションは使えません。
- FOLLOW を使わない曲の後ろには、無音を1秒程度確保してください。
  曲末の停止判定に最大1フレーム(約30ms)の遅れがあるためです。

## 操作

| ボタン | 動作 |
|---|---|
| GO | 選択曲の先頭から再生。リージョン終端で自動停止 |
| NEXT | リピートを解除。シーク無しでそのまま次のセクションへ |
| STOP | 即時停止。再生中は GO の位置が STOP に変わる |

スクリプト外で再生を始めた場合も、再生位置から曲を特定して自動的に
管理下へ取り込みます。

## ループ

スクリプトは、再生中のセクションに合わせて REAPER のループ範囲
(タイムセレクション)を更新し続けます。リピートの ON/OFF には関与しません。

回したいセクションを鳴らしている最中に REAPER 標準の
**「Transport: Toggle repeat」** を叩けばそのセクションが回り、
もう一度叩けば抜けます。フットスイッチや MIDI はこの標準アクションに
割り当ててください。スクリプトへの MIDI アサインは不要です。

ループ動作自体は REAPER のオーディオエンジンが処理するため、
サンプル精度で動作します。

編集タブでセクションに LOOP 指定を付けた場合のみ、そこへ入った時点で
自動的にリピートを ON にします。指定が無いセクションではリピートに
触れないので、手動操作と衝突しません。

## FOLLOW

編集タブでチェックを入れた曲は、前の曲が終わったときに自動で始まります。

- リージョンが隣接している場合 … シーク無しで連続。継ぎ目が出ません
- 間隔が空いている場合 … 次曲の頭へシークして継続します

1曲目に付けても効果がないため、`!` を表示します。

## 選択の追従

再生中は再生位置、停止中は編集カーソルとタイムセレクションに追従します。
無効化はできません。

セクション表の選択行は「次のセクション」を指します。現在地は `>` で
示されるため、現在と次が同時に読めます。

## 保存先

| 内容 | 保存先 |
|---|---|
| LOOP 設定、FOLLOW 設定 | プロジェクト (SetProjExtState) |
| ドッキング状態 | グローバル (SetExtState) |

設定は曲名とセクション名で識別するため、リージョンやマーカーを時間軸上で
移動しても維持されます。名前を変更した場合は設定し直しになります。

## ファイル構成

```
ReaQLine.lua           エントリポイント。状態を持ち、各モジュールを繋ぐ
reaqline/
  config.lua           定数と配色
  imgui.lua            ReaImGui 初期化、フォント、キーボード制御
  model.lua            プロジェクト走査、設定の保存と復元
  transport.lua        再生制御、ループ範囲、進行管理
  widgets.lua          描画の共通部品
  ui_live.lua          本番タブ
  ui_edit.lua          編集タブ
  ui.lua               ウィンドウ枠、ドッキング、フォーカス返却
```

しきい値、配色、フォントサイズの調整は `config.lua` のみで完結します。

## トラブルシュート

フッターの `DBG` を有効にすると、内部状態が表示されます。

- `KB` 行 … キーボード関連設定の適用結果
- `DBG` 行 … 追従の基準、再生位置、リージョン終端、選択状態

日本語のリージョン名が文字化けする場合は、ReaImGui を更新するか、
名前をローマ字にしてください。
